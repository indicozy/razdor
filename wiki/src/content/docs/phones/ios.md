## Установка (экспериментально)

Для iPhone и iPad с iOS 14 и новее в выпусках на GitHub доступен файл **razdor.ipa**. Это экспериментальная версия. Новый IPA ставится поверх старого.

Файл не подписан, поэтому для установки используйте **AltStore** или **Sideloadly** со своим Apple ID. Самостоятельно подписывать файл не требуется.

### Способ 1: AltStore
1. Запустите AltServer на компьютере.
2. Установите AltStore на телефон через AltServer.
3. В приложении AltStore перейдите на вкладку «My Apps» и нажмите «+».
4. Выберите скачанный файл **razdor.ipa**.

### Способ 2: Sideloadly
1. Подключите телефон к компьютеру.
2. Перетащите файл **razdor.ipa** в окно программы Sideloadly.
3. Введите свой Apple ID.

:::caution
При использовании бесплатного Apple ID программа будет работать только **7 дней**. После этого её нужно подписать заново.
:::

:::tip
Если AltServer и телефон находятся в одной Wi-Fi сети, AltStore сможет обновлять подпись автоматически. Если нет — установите IPA заново через Sideloadly. Ваши сохранения при этом не удалятся.
:::

## Настройка системы

Если у вас iOS 16 или новее, необходимо выполнить два действия:
1. Включите **Режим разработчика**: «Настройки» → «Конфиденциальность и безопасность» → «Режим разработчика».
2. Доверьте профилю разработчика: «Настройки» → «Основные» → «VPN и управление устройством».

## Установка игровых файлов

Чтобы игра работала корректно, нужно перенести папку с контентом на устройство.

1. Скопируйте папку игры «Времена раздора» (в которой находятся папка `Maps_Rus` и файл `Rus_Units.ini`).
2. Поместите её по пути: «Файлы» → **На iPhone** → **Раздор** → папка **DiscordTimes**.

:::note
На компьютере этот путь можно найти через Finder (или iTunes): выберите устройство → «Файлы» → «Раздор».
:::

После копирования откройте Razdor и нажмите кнопку **«Проверить снова»**. Если не нажать, движок проверит файлы сам через несколько секунд на титульном экране.

## Хранение данных

Сохранения и журнал работы находятся в папке:
«Файлы» → На iPhone → Раздор → **Razdor** (внутри находится папка `saves`).

Для доступа к этим данным дополнительные разрешения не требуются.

Кэш картинок хранится отдельно, в кэше приложения (в «Файлах» его не видно), и занимает не больше 256 МБ.

## Управление

На iOS управление осуществляется только касанием. Доступны те же жесты, что и на Android. Режим тачпада включается в том же окне настроек, что и на Android.
