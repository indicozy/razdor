## Keys

Press **F1** on any screen to see its list of keys.

:::note
Keys do nothing while you type text (the hero's name, a save name, the editor field) or while a dialog or question is open. In a dialog, **N** means "No", and any other key except Tab, Alt and the up and down arrows means "Yes".
:::

### Common keys

| Key | What it does |
| :--- | :--- |
| F1 | The list of keys for the current screen (closed with F1, Esc or a click) |
| F2 | The next language in the list (Russian, English, the translations found) |
| F9 | Quick load: loads the quick save |
| N | Music off / on |

### Main menu and hero choice

| Key | What it does |
| :--- | :--- |
| Esc in the main menu | Quits the game at once, as in the original |
| Esc in hero choice | Back to the main menu |

### World map

| Key | What it does |
| :--- | :--- |
| Click, then click the same place | Show the route and the time to it, then walk it |
| Click or any key while walking | Stop at the end of the current step (keys that only change the view, the music or the help do not stop it) |
| Right click or Space | Stop: a walk stops at the end of the current step, waiting and spell casting stop at once, the shown route is removed |
| Right button (held) | Tooltip about the army or building under the mouse |
| Right button (held) and mouse move | Drag the map |
| Mouse wheel, + / − | Zoom |
| Arrows, mouse at the window edge | Scroll the map |
| 1 / 4, or left / right click on the time panel | Wait 1 or 4 hours |
| F4 / F5 | F4 — wait without end; F5 — stop waiting |
| M | Minimap |
| Tab | Centre the camera on the hero |
| J / B / A | Hero's diary / Spell book / Hero and army |
| F5 | Quick save (replaces the previous one) |
| Esc | Closes the minimap; if there is none, opens the game menu ("Leave the game", main menu, restart) |
| `~` (the key left of 1; Ё on the Russian layout) | Cheat console |

### Windows (army, building, journal, spell book, menu)

| Key | What it does |
| :--- | :--- |
| Esc | Back (to the map or to the building) |
| A letter or Ctrl+F | Gear filter: search items in the backpack or at the market |
| Enter (while searching) | Select the first match |
| Esc (while searching) | Clear the search field |

### Specific windows

**Hero's diary:**

| Key | What it does |
| :--- | :--- |
| Left / right | Switch diary tabs |
| Up / down, mouse wheel | Choose an entry and scroll |
| J | Close |

**Spell book:**

| Key | What it does |
| :--- | :--- |
| Click | Cast a spell (for an enemy spell, choose the army) |
| B | Close |

**Army:**

| Key | What it does |
| :--- | :--- |
| A | Close the window |

### Battle

| Key | What it does |
| :--- | :--- |
| Q / Enter (before the first move) | Quick battle |
| Space | As a click on your own unit card |
| Q | Finish automatically |
| Enter | "OK on the result" in the totals |
| W | Watch the AI play both sides / take control back |
| S (while watching) | Speed 1×, 2×, 4× |
| Q (while watching) | Skip to the end, with the same result |
| Esc | Battle exit menu (exit, main menu, restart) |

**Custom battle setup and totals:**

| Key | What it does |
| :--- | :--- |
| Enter (in setup) | Fight |
| Esc (in setup) | Back to the main menu |
| Enter (in totals) | Again |
| Esc (in totals) | Change armies |

:::tip
Keys for the map, windows, minimap and F1 can be changed: **"Options"** → **"Advanced…"** → **"Keys…"**. Click a key, then press the new one. A key already used by another action moves to it. On the map, the **"Change the keys…"** button at the bottom of the key list (F1) opens the same window.
:::

## Gamepad

Razdor can be played fully with a gamepad (Xbox, PlayStation and similar; Windows, Linux and macOS). The original has no gamepad support. The gamepad moves its own mouse pointer, so everything works the same as with the mouse.

| Button | What it does |
| :--- | :--- |
| Left stick or D-pad | Moves the pointer (slow at first, for precise aiming, then faster) |
| A (cross) | Left mouse button; hold to drag |
| B (circle) | Right mouse button (tooltip, stop; moving the pointer while held drags the map) |
| Right stick | Scrolls the world map; the mouse wheel in lists and texts |
| LB / RB | Mouse wheel up / down (map zoom, list scrolling) |
| Start | Esc (menu, back); it does not close the game on the title screen |
| X (square) | Enter (OK, "Yes", quick battle) |
| Y (triangle) | Space (stop on the map, click on your unit card in battle) |

:::caution
The gamepad works only while the game window is active. If you move the mouse, the mouse takes over again. Hero and save names are still typed on the keyboard.
:::
