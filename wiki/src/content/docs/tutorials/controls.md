## Клавиши

Нажмите **F1** на любом экране, чтобы увидеть список его клавиш.

:::note
Клавиши не действуют, пока вы набираете текст (имя героя, название сохранения, поле редактора) или пока открыт диалог или вопрос. В диалоге клавиша **N** означает «Нет», а любая другая клавиша, кроме Tab, Alt и стрелок вверх и вниз, означает «Да».
:::

### Общие клавиши

| Клавиша | Что делает |
| :--- | :--- |
| F1 | Список клавиш текущего экрана (закрывается F1, Esc или щелчком) |
| F2 | Следующий язык списка (русский, английский, найденные переводы) |
| F9 | Быстрая загрузка: загружает быстрое сохранение |
| N | Музыка выключена / включена |

### Главное меню и выбор героя

| Клавиша | Что делает |
| :--- | :--- |
| Esc в главном меню | Сразу выход из игры, как в оригинале |
| Esc в выборе героя | Назад в главное меню |

### Карта мира

| Клавиша | Что делает |
| :--- | :--- |
| Щелчок, затем щелчок по тому же месту | Показать путь и время до него, затем пройти его |
| Щелчок или любая клавиша в пути | Остановиться в конце текущего шага (клавиши, которые меняют только вид, музыку или справку, не останавливают) |
| Правый щелчок или Пробел | Стоп: путь останавливается в конце текущего шага, ожидание и сотворение заклинания прекращаются сразу, показанный путь убирается |
| Правая кнопка (зажата) | Подсказка об армии или здании под мышью |
| Правая кнопка (зажата) и движение мыши | Перетаскивание карты |
| Колесо мыши, + / − | Масштаб |
| Стрелки, мышь у края окна | Прокрутка карты |
| 1 / 4, или левый / правый щелчок по панели времени | Ждать 1 или 4 часа |
| F4 / F5 | F4 — ждать без конца; F5 — перестать ждать |
| M | Мини-карта |
| Tab | Навести камеру на героя |
| J / B / A | Дневник героя / Книга заклинаний / Герой и его армия |
| F5 | Быстрое сохранение (заменяет предыдущее) |
| Esc | Закрывает мини-карту; если её нет, открывает меню игры («Выход из игры», главное меню, рестарт) |
| `~` (клавиша слева от 1; Ё в русской раскладке) | Консоль читов |

### Окна (армия, здание, журнал, книга заклинаний, меню)

| Клавиша | Что делает |
| :--- | :--- |
| Esc | Назад (на карту или в здание) |
| Буква или Ctrl+F | Отбор снаряжения: поиск вещей в рюкзаке или на рынке |
| Enter (при поиске) | Выбрать первое совпадение |
| Esc (при поиске) | Очистить строку поиска |

### Отдельные окна

**Дневник героя:**

| Клавиша | Что делает |
| :--- | :--- |
| Влево / вправо | Переключение вкладок дневника |
| Вверх / вниз, колесо | Выбор записи и прокрутка |
| J | Закрыть |

**Книга заклинаний:**

| Клавиша | Что делает |
| :--- | :--- |
| Щелчок | Сотворить заклинание (для вражеского — выбрать армию) |
| B | Закрыть |

**Армия:**

| Клавиша | Что делает |
| :--- | :--- |
| A | Закрыть окно |

### Битва

| Клавиша | Что делает |
| :--- | :--- |
| Q / Enter (до первого хода) | Быстрый бой |
| Пробел | Как щелчок по своей карточке |
| Q | Доиграть самим (автоматически) |
| Enter | «Готово» в итогах |
| W | Смотреть, как ИИ играет за обе стороны / вернуть управление |
| S (при просмотре) | Темп 1×, 2×, 4× |
| Q (при просмотре) | Сразу к концу, с тем же итогом |
| Esc | Меню выхода из битвы (выход, главное меню, рестарт) |

**Подготовка своего боя и итоги:**

| Клавиша | Что делает |
| :--- | :--- |
| Enter (в подготовке) | В бой |
| Esc (в подготовке) | Назад в главное меню |
| Enter (в итогах) | Ещё раз |
| Esc (в итогах) | Сменить армии |

:::tip
Клавиши карты, окон, мини-карты и F1 можно переназначить: **«Настройки»** → **«Ещё…»** → **«Клавиши…»**. Щёлкните по клавише, затем нажмите новую. Клавиша, занятая другим действием, переходит к нему. На карте то же окно открывает кнопка **«Изменить клавиши…»** внизу списка клавиш (F1).
:::

## Геймпад

Всю игру можно пройти с геймпадом (Xbox, PlayStation и подобные; Windows, Linux и macOS). В оригинале этого нет. Геймпад управляет своим указателем мыши, поэтому всё работает так же, как мышью.

| Кнопка | Что делает |
| :--- | :--- |
| Левый стик или крестовина | Движение указателя (сначала медленно, для точного наведения, затем быстрее) |
| A (крест) | Левая кнопка мыши; удерживайте, чтобы перетаскивать |
| B (круг) | Правая кнопка мыши (подсказка, стоп; при движении тащит карту) |
| Правый стик | Прокрутка карты мира; в списках и текстах — колесо |
| LB / RB | Колесо вверх / вниз (масштаб карты, прокрутка списков) |
| Start | Esc (меню, назад); на титульном экране не закрывает игру |
| X (квадрат) | Enter (ОК, «Да», быстрый бой) |
| Y (треугольник) | Пробел (стоп на карте, щелчок по своей карточке в битве) |

:::caution
Геймпад работает, только пока окно игры активно. Если вы сдвинете мышь, снова работает мышь. Имена героя и сохранения всё равно набираются с клавиатуры.
:::
