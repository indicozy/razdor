## Как пользоваться

Дополнение Razdor. Над рюкзаком героя и армии стоит ряд кнопок.

1. Откройте окно **«Герой и армия»** (или рынок в городе).
2. Над рюкзаком — ряд кнопок: восемь групп (шлемы, доспехи, оружие, щиты, кольца, амулеты, зелья, прочее) и кнопка **«Поиск»** последней. Название группы показывается, когда наводите на неё курсор.
3. Щёлкните по группе: в рюкзаке останутся только предметы этой группы, а её кнопка останется нажатой.
4. Щёлкните по нажатой кнопке ещё раз: снова видны все предметы.
5. Поиск: щёлкните по кнопке **«Поиск»** (или нажмите `Ctrl+F`) и наберите слово. Список сужается по мере набора: остаются предметы, в названии, типе, характеристиках, бонусе или описании которых есть **все** набранные слова. **Enter** берёт первый найденный, **Esc** очищает строку.
6. Порядок предметов: правый щелчок по кнопке **«Поиск»** переключает порядок по кругу: как есть, по имени А–Я, по имени Я–А, цена ↓, цена ↑. Рюкзак каждый раз прокручивается к началу.

:::tip
Регистр при поиске не важен. Буква «Ё» считается как «Е».
:::

## Хорошо знать

* Пока строка поиска пуста, буквы **A** и **N** работают по-прежнему (A закрывает окно армии, N выключает музыку). Для поиска сначала щёлкните по кнопке или нажмите `Ctrl+F`.
* Поиск идёт по предметам, которые видны в выбранной группе и порядке.
* **Esc** (первое нажатие) очищает строку поиска, **Esc** (второе) закрывает окно.
* На экране армии **Enter** сразу надевает или выпивает предмет выбранному воину. Пока открыто дерево улучшений, ряда кнопок нет.
* На рынке ряд из восьми групп стоит над списком товаров. Строки поиска нет на виду, пока вы не щёлкнете по списку, не нажмёте `Ctrl+F` или не наберёте букву. Enter выбирает первый найденный предмет для «Купить» или «Продать». Щелчок по заголовку «Название» или «Цена» сортирует список.
* В рюкзаке совпавшие части названий перечислены в поле описания, пока вы не наведёте курсор на предмет.
