`razdor-translate` — это отдельная программа для создания локализованных версий ваших карт и игровых данных с помощью языковых моделей (LLM).

## Основные возможности

Программа позволяет создавать копии карт (например, из `Имя.DTm` в `Имя_en.DTm`) и переводить игровые данные.

*   **Поддержка API:** Работает с любым API, совместимым с OpenAI. Можно использовать локальные серверы (Ollama, LM Studio) или облачные сервисы (OpenAI, OpenRouter, DeepSeek).
*   **Перевод карт:** Создаются копии карт для выбранного языка. В поле «Буквы» выберите «латиница или кириллица»: такие карты откроет и оригинальная игра. «Любое письмо» (иероглифы, деванагари и т.д.) даёт карты только для Раздора.
*   **Перевод данных игры:** Переводятся названия и описания воинов, предметов, заклинаний и тексты игры. Результат сохраняется в отдельные `.ini` файлы (например, `Eng_Units.ini`).
*   **Пересказ (русский):** При выборе русского языка программа не просто переводит, а переписывает тексты на русском в заданном вами стиле.

## Настройка и параметры

Для работы программы можно использовать графический интерфейс или командную строку.

### Параметры интерфейса
*   **«Проверить»**: Проверяет связь с API и наличие нужной модели.
*   **«Контекст»**: Указывает объем токенов, который модель помнит за один раз.
*   **«Переводить на»**: Выбор целевого языка.
*   **«Буквы»**: Выбор между латиницей (для совместимости с оригиналом) и родным письмом языка.
*   **«Стиль перевода»**: Ваши инструкции для модели (например, «как летопись»).
*   **«Контекст» (заметки о картах)**: что модели важно знать о картах: кто есть кто, сюжет, какие имена не менять.
*   **«Журнал запросов»**: Открывает файл со всеми запросами и ответами модели.

:::tip
Адрес API можно вводить без `/v1`. Переводчик допишет его автоматически.
:::

### Работа без графического окна
Если вы запускаете программу через терминал, используйте следующие ключи:
*   `--map "Имя карты"` — перевести конкретную карту.
*   `--data` — перевести игровые данные.
*   `--language`, `--style`, `--notes`, `--fresh` — установка языка, стиля, контекста и принудительный перезапуск перевода.
*   `--show-prompt` — вывести инструкции, которые уходят модели, в журнал.

## Процесс перевода

1.  Выберите карту или кампанию в списке слева.
2.  Настройте параметры языка и стиля.
3.  Нажмите «Перевести».

Программа сначала переводит имена, а затем тексты, используя имена из словаря для единообразия. Каждый ответ модели проверяется на сохранность разметки и переменных (например, `#HERONAME`). Если возникла ошибка, программа попробует повторить запрос.

:::caution
Если вы изменили модель, стиль или контекст, старый перевод не обновится автоматически. Нужно использовать функцию «Перевести заново».
:::

## Сохранение результатов

При завершении работы программа может записывать готовые файлы в папку карт.
*   Кнопка **«Записать английские карты»** записывает то, что уже переведено.
*   Для замены уже существующих копий нужно нажать кнопку второй раз.

:::note
Переведенные карты создаются на основе ваших файлов. Не добавляйте их в общий репозиторий проекта.
:::
