## Консоль читов

Консоль позволяет вводить команды для изменения игрового процесса. Её можно открыть как на карте мира, так и во время битвы.

Чтобы открыть консоль, нажмите клавишу **~** (тильда, находится слева от клавиши «1» или «Ё» в русской раскладке). После нажатия поверх верхней части экрана появится командная строка.

:::note
Пока консоль открыта, все нажатия клавиш уходят в неё, а не в игру.
:::

### Управление консолью
* **PgUp / PgDn** или **колесо мыши**: прокрутка истории вывода.
* **Стрелки вверх и вниз**: возврат к предыдущим введенным командам.
* **~** или **Esc**: закрыть консоль.

### Подсказки при наборе

По мере набора под строкой ввода появляется список подсказок (до 8 строк): названия команд, а после `item `, `spell ` или `unit ` — названия предметов, заклинаний и отрядов текущей игры. У строки команды написан её вид (например, `gold N`), а серым — описание.

Клавиша Tab дописывает первую подсказку, каждое следующее нажатие Tab переходит к следующей строке (Shift+Tab — назад). Стрелки вверх и вниз выбирают строку в списке, пока он открыт; история введённых команд в это время не вызывается. Enter дописывает выбранную строку и выполняет её, только если это команда без аргументов (например, `reveal`); во всех остальных случаях Enter лишь дописывает строку, и её нужно отправить ещё раз. На телефоне достаточно коснуться строки списка: она дописывается так же, как по Tab.

### Команды

Названия команд пишутся на английском языке. Регистр не имеет значения. Если вы вводите название предмета, заклинания или юнита, движок сначала ищет точное совпадение, затем совпадение по началу слова, а затем по вхождению в слово. Если под критерии подходят несколько объектов, консоль сообщит об этом.

| Команда | Что делает |
| --- | --- |
| `help` | Показывает список всех команд с описанием на языке интерфейса |
| `gold N` | Даёт N золота (отрицательное N отнимает золото) |
| `mana N` | Даёт N маны (отрицательное N отнимает ману) |
| `reveal` | Открывает всю карту |
| `heal` | Лечит армию и поднимает её павших |
| `xp N` | Даёт N опыта каждому живому воину в армии (уровни растут как после битвы) |
| `level N` | Устанавливает герою уровень N |
| `item <номер или название>` | Добавляет предмет в рюкзак |
| `spell <номер или название>` | Добавляет заклинание в книгу (максимум 15) |
| `unit <номер или название> [уровень]` | Добавляет воина в армию (если есть место) с указанным уровнем |
| `time H` | Перематывает время на H часов (влияет на полдни, события и ИИ) |
| `win` | Завершает битву вашей победой |
| `lose` | Завершает битву вашим поражением |
| `god` | Включает и выключает неуязвимость армии в битве |
| `speed N` | Ускоряет только героя: за его шаг проходит в N раз меньше игрового времени, поэтому вражеские армии за это время успевают меньше (1 — обычная скорость) |
| `noclip` | Включает/выключает прохождение сквозь препятствия |
| `peace` | Включает/выключает режим мира (враги не нападают на героя, но герой может напасть на них) |
| `routes` | Включает/выключает отображение путей вражеских армий на мини-карте |

:::caution
Команда `peace` не влияет на гарнизоны, охрану зданий и битвы, прописанные в событиях сценария.
:::

### Важные особенности
* **Сохранения**: Использование читов помечает сохранение. В списке загрузки после названия сценария будет стоять пометка «(читы)».
* **Журнал**: Каждая использованная команда записывается в журнал игры.
* **Битвы**: Во время боя армия, её опыт и время не меняются. Однако команды `win` и `lose` работают и в бою, завершая его с соответствующим итогом (окно итогов, опыт, потери).
