Файлы игры и моды (например, Community Update Evolution Mod) ставятся в Razdor двумя способами.

## Через «Обновить игру из архива…»

1. Откройте окно «Настройки звука, графики и игры».
2. Нажмите кнопку **«Обновить игру из архива…»**.
3. Выберите архив `.zip` или `.7z`.

Что будет:

* **Полная замена.** Если в архиве вся папка игры, игра в папке `DiscordTimes` заменяется (после вопроса). Сохранения остаются.
* **Патч или мод.** Если в архиве только часть файлов, они ставятся поверх игры.
* **Безопасность.** Архив сначала распаковывается рядом с игрой, и игра меняется только после успешной распаковки. При ошибке игра остаётся прежней.

:::note
Кнопка есть, когда игра лежит в папке `DiscordTimes`, которую использует Razdor. Копия игры в другой папке не меняется.
:::

## Запуск с модом на компьютере

Мод Discord Times — это изменённая установка игры. Укажите Razdor папку этой установки через переменную `RAZDOR_DT_DIR`:

```sh
export RAZDOR_DT_DIR="/path/to/Discord Times"
```

Подробнее о поиске игры: [Установка игры](/razdor/wiki/start/install-game/).
