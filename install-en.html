How to install Razdor

Razdor is a program that runs Discord Times, but it does not contain the game itself. You need your own copy of the game: Razdor reads its maps, data and graphics while it runs and changes nothing in it.

  • What you need
  • Windows
  • Linux
  • macOS
  • Android
  • iPhone and iPad
  • Updates
  • Won't start

What you need

  • Your own copy of Discord Times, version 1.8.1, with Community Update 1.2.
  • Razdor, the program from a release on GitHub. Each system has its own file.
  • System: Windows, Linux or macOS 11 and later; Android 8 or later (ARM processors); iPhone or iPad with iOS 14 or later.

Where to get the game

Discord of the Discord Times players (not Razdor's): discord.gg/wmMksmWFDM

You don't have to unpack the game's archive (7z) and the update's archive (zip) yourself: download them to Downloads (on Android to Download, on iPhone to Files → On My iPhone → Razdor), and Razdor, not finding the game, offers an «Unpack the game archive» button.

Where to get Razdor

Releases page: github.com/indicozy/razdor/releases. Take the newest release: Razdor.exe, razdor, razdor-macos, razdor.apk, razdor.ipa.

Razdor is made for Community Update 1.2. The Evolution mod (tested with version 9.0 on Community Update) works too: put Razdor into the game folder with the mod installed. Mods that change DiscordTimes.exe itself are not supported.

On a computer

The program has to be in the game folder, next to DiscordTimes.exe. Then Razdor finds the game by itself and plays exactly this copy.

Windows

  1. 1

    Download Razdor.exe from the newest release.

  2. 2

    Put Razdor.exe into the game folder, next to DiscordTimes.exe. The rest is already there: the Maps_Rus folder and the Rus_Units.ini file.

  3. 3

    Double-click Razdor.exe to start it.

If the game is somewhere else, give its folder in a .env file next to the program: RAZDOR_DT_DIR="path to the game folder".

Linux

  1. 1

    Download razdor from the newest release.

  2. 2

    Put razdor into the game folder, next to DiscordTimes.exe.

  3. 3

    Start razdor from a terminal opened in the game folder.

Sound goes through ALSA (the libasound.so.2 library is on any desktop; PipeWire and PulseAudio provide the default device). The menu icon is described in the README.

macOS

  1. 1

    Download razdor-macos from the newest release.

  2. 2

    On a Mac the game stands inside a Wine or CrossOver bottle. Put razdor-macos into the game folder, next to DiscordTimes.exe.

  3. 3

    Before the first start, remove the macOS block. In Terminal, in the folder with the program, run the command. Or right-click the file and choose Open in Finder.

  4. 4

    Start razdor-macos with a double-click. The program opens in a Terminal window.

The program is not signed by its developer, so macOS blocks it after the download: that is step 3.

Android (trial version)

Touch controls: the gestures are described in the README. There is no update inside the program: a new APK installs over the old one. Saves are kept in the Razdor folder in internal storage and are not lost when the app is reinstalled.

  1. 1

    Install razdor.apk. Android 8 or later is needed. Allow installs from this source in the Android settings.

  2. 2

    Put the Discord Times game folder into internal storage, in a folder named DiscordTimes (Internal storage/DiscordTimes) or in Download. It must contain the Maps_Rus folder and the Rus_Units.ini file, as the folder with DiscordTimes.exe on a computer does.

  3. 3

    Give Razdor All files access. If the game is not visible, the title screen shows a Grant access button, which opens the right settings page. By hand: Settings → Apps → Special app access → All files access → Razdor. On Android 8–10 the button asks for the usual file permission.

  4. 4

    Go back to Razdor and tap Check again. The game is found without a restart. The title screen also checks the folder by itself every few seconds.

iPhone and iPad (trial version)

Touch controls, as on Android. There is no update inside the program: a new IPA installs over the old one. The file is not signed, so it is installed with AltStore or Sideloadly using your own Apple ID; you do not need to sign anything yourself.

  1. 1

    Download razdor.ipa from the newest release. iOS 14 or later is needed.

  2. 2

    Install the IPA in one of two ways:

    • AltStore (altstore.io): on the computer, start AltServer, then install AltStore on the phone through AltServer. In AltStore, on the My Apps tab, tap “+” and choose the IPA.
    • Sideloadly (sideloadly.io): connect the phone to the computer, drag the IPA into the window and enter your Apple ID.
  3. 3

    On iOS 16 and later, turn on Developer Mode: Settings → Privacy & Security → Developer Mode. Then trust the developer profile: Settings → General → VPN & Device Management.

  4. 4

    A free Apple ID signs the program for 7 days; after that it has to be signed again. AltStore does this itself if AltServer runs on the computer on the same Wi‑Fi network. Otherwise install the IPA again with Sideloadly. Saves stay.

  5. 5

    Copy the Discord Times game folder (with the Maps_Rus folder and the Rus_Units.ini file) to Files → On My iPhone → Razdor → DiscordTimes. From a computer, do the same with Finder (or iTunes): the device → Files → Razdor.

  6. 6

    Open Razdor and tap Check again. The title screen also checks the folder by itself every few seconds.

Saves, the log and the image cache are in Files → On My iPhone → Razdor → Razdor (the saves folder inside). No permissions are needed for this.

Updates

  • On a computer Razdor checks for a newer release when it starts. When one exists, at a quiet moment (the title screen, the settings, or the map with no other windows; never in a battle) it offers the update. “Update” downloads it, checks it against the release's SHA256SUMS and puts it in place of the program; the new version runs from the next start.
  • Settings → “More…” → “Updates”: “Ask” (the default), “Always” (no window) or “Off”. The “Check” button looks for a new version at once. The system curl is needed (it is on Windows 10 and later, macOS and almost any Linux).
  • On Android and iPhone there is no update inside the program: a new APK or IPA installs over the old one.

If it does not start

  • Razdor cannot find the game. The screen says “Discord Times not found.” Check that the program lies next to DiscordTimes.exe (computer), and on the phone that the game folder is in place: Android — Internal storage/DiscordTimes or Download; iPhone — Files → On My iPhone → Razdor → DiscordTimes. The folder must contain Maps_Rus and Rus_Units.ini. While the game is missing, Razdor runs its own demo kingdom: its own units and map, without the original's scenarios.
  • Android: the game is not visible. Give All files access (step 3), then tap Check again. Without this access the game cannot be read, and the title screen stays with the demo map.
  • Windows: “WGL_ARB_pixel_format is required” or no OpenGL driver. Razdor needs OpenGL 2. This happens in a remote desktop (RDP) session and in virtual machines without a driver. Put a software OpenGL from Mesa (opengl32.dll, and in new releases also libgallium_wgl.dll from the x64 folder of mesa-dist-win) next to Razdor.exe; or connect without RDP; or install a graphics driver. Razdor shows this advice itself instead of a bare error.
  • It does not start, or plays differently from the original. Razdor writes a razdor.log file: on Windows in %APPDATA%\razdor\, on Linux in ~/.local/share/razdor/, on macOS in ~/Library/Application Support/razdor/. The previous run is in razdor.previous.log. The last line shows the step where the program stopped.
