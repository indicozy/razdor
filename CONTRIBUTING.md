# Как помочь Раздору

Раздор — открытый движок для «Времён раздора» (Discord Times). Он играет оригинальные сценарии
по оригинальным правилам и читает карты, данные и графику из вашей собственной копии игры.
Главное правило проекта — **как в оригинале**: Раздор повторяет игру один в один, включая её
ошибки. Отличия от оригинала появляются, только когда об этом договорились.

## Сообщить об ошибке

Откройте issue и приложите что сможете:

- что вы делали и что увидели;
- скриншот или короткое видео;
- сохранение (`.rzsave`) из момента прямо перед ошибкой — по нему ошибку проще всего повторить;
- карту и версию Раздора (видна в главном меню и в журнале `razdor.log`);
- как это работает в оригинале, если знаете.

Сохранение не попадает в репозиторий: мы используем его только для проверки.

## Предложить изменение

Хорошее изменение:

- **Приближает Раздор к оригиналу.** Сначала выясните, как это устроено в оригинале: описания
  правил лежат в `docs/reference/original-mechanics/`, а если там нет ответа — разберите
  `DiscordTimes.exe` (например, в Ghidra). В коде и в описании коммита укажите адреса
  оригинала (`0x4…`), на которые опирается изменение.
- **Сопровождается тестом**, который падает без изменения.
- **Добавляет строку в `changelog/unreleased.md`** — коротко и простыми словами, как это заметит
  игрок, без технических подробностей. Сам `CHANGELOG.md` собирается из папки `changelog/`
  скриптом `scripts/changelog.sh`, вручную его не правьте.

Если хотите сделать что-то, чего в оригинале нет или что работает там иначе, сначала откройте
issue и обсудите: такие изменения принимаются только по согласованию.

Pull request делайте в ветку `main`. Изменения, которые повторяют оригинал, потом переносятся
и в ветку `dt-original` — это сделаем мы.

## Чего никогда нет в репозитории

Ничего из игры: карт, файлов `.ini`, текстов, графики (`.lit`, `.ugs`), звуков, распакованных
картинок, скриншотов оригинала. И ничего личного: сохранений, журналов, настроек, путей
вашего компьютера. Раздор поставляет только движок; всё остальное он читает из копии игры
игрока. Pull request с файлами игры принят не будет.

## Сборка и тесты

Нужен Rust (версия закреплена в `rust-toolchain.toml`).

```sh
cargo build --release
cargo test --release
cargo clippy --all-targets -- -D warnings
```

Тесты, которым нужны файлы игры, без копии игры пропускаются. Чтобы запустить и их, укажите
папку игры (с `DiscordTimes.exe`):

```sh
export RAZDOR_DT_DIR="/path/to/Discord Times"
cargo test --release
```

Перед pull request прогоните тесты с `RAZDOR_DT_DIR`: CI на GitHub копии игры не имеет и эти
тесты не проверяет.

## С чего начать чтение

- `docs/flows/README.md` — как устроен код: бой, ход по карте, здания, окна, графика,
  сохранения, тесты. Документы на английском, как и код.
- `docs/reference/original-mechanics/` — правила оригинала.
- `docs/PLAYTEST_NOTES.md` — отчёты игроков и что по ним найдено.
- `CLAUDE.md` — краткие правила проекта.

## Лицензия

Раздор распространяется по лицензии GPL-3.0-only (`LICENSE`) с дополнительными условиями из
`NOTICE`. Перед тем как ваш первый pull request будет принят, вы подписываете соглашение
участника (`CLA.md`): вы остаётесь автором своего кода, а автор проекта может распространять
его и на других условиях (например, сборки для магазинов, где GPL нельзя использовать).
Подписать просто: бот CLA попросит об этом в вашем первом pull request, и вы отвечаете
комментарием

    I have read the CLA Document and I hereby sign the CLA

Подпись действует на весь ваш вклад в Раздор.
