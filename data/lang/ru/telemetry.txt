# Razdor interface in Russian: the analytics' questions and settings (`telemetry`, `ui::telemetry_view`).
# "English = Russian", one per line; \n is a line break, {name} a value filled in by the game.

Help Razdor? = Помочь Раздору?
Razdor can send anonymous play statistics, performance figures, crash reports and battle records, to make it better. No names, no chat, no typed text. You can change this in Settings any time. = Раздор может отправлять анонимную статистику игры, данные о быстродействии, отчёты о вылетах и записи боёв, чтобы становиться лучше. Без имён, чатов и введённого текста. Это можно поменять в настройках в любой момент.
What we send = Что мы отправляем
The game crashed = Игра вылетела
The game crashed last time. Send the report with the save, so the developer can repeat it? = В прошлый раз игра вылетела. Отправить отчёт с сохранением, чтобы разработчик мог повторить?
The game crashed last time. Send the report, so the developer can look into it? = В прошлый раз игра вылетела. Отправить отчёт, чтобы разработчик мог разобраться?
Send = Отправить
Help Razdor = Помогать Раздору
Sent anonymously: game statistics (launches, maps, events), crash reports, performance figures and battle records. Nothing you type is sent: no names of heroes or saves, no chat. The full list is on the page «What we send», linked from the question «Help Razdor?». = Отправляется анонимно: статистика игры (запуски, карты, события), отчёты о вылетах, замеры производительности и записи боёв. Ничего из написанного вами не уходит: ни имена героев или сохранений, ни чаты. Полный список на странице «Что мы отправляем», её ссылка есть в окне «Помочь Раздору?».
My id = Мой идентификатор
Show = Показать
Copy = Копировать

Delete my data = Удалить мои данные
Delete my data? = Удалить мои данные?
The server deletes everything sent under this id: statistics, crash reports, battle records. A new id is made, and nothing more is sent under the old one. = Сервер удалит всё, что отправлено под этим идентификатором: статистику, отчёты о вылетах, записи боёв. Будет создан новый идентификатор, а под старым ничего больше не отправится.
Delete… = Удалить…
New id = Новый идентификатор
New id? = Новый идентификатор?
A new id is made. Data queued under the old id is not sent, and the old id's data stays on the server. = Будет создан новый идентификатор. Данные, ждущие отправки под старым, не уйдут, а уже отправленное остаётся на сервере.
New… = Новый…
