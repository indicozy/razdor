Razdor

The same RPG, on any device: Discord Times on Windows, Linux, macOS, Android and iOS

How it works

×

Razdor is a new engine for Discord Times («Времена раздора», Aterdux, 2004). It is written from scratch and contains nothing from the original game itself. It reads the maps, data, art, sounds, music and texts from your installed copy while you play, and changes nothing in it.

The rules follow the original: battles on the 2×6 field, initiative, rows and magic, experience and promotions, the economy, events and quests work as in the game, the Community Update's included.

What Razdor plays

  • Every scenario and campaign in the game folder: «Раменское королевство», «Сказка странствий» and the rest.
  • The world map with its fog of war, towns, castles and villages, armies with goals of their own, ships.
  • Items, spells, the quest journal, saves.
  • A map editor whose maps the original opens too.
  • Russian and English interface; the game's own fonts or a modern one, your choice.
  • Mouse, keyboard or gamepad.
  • Any resolution and window shape; interface scale up to ×4.
  • Phones and tablets (Android, iOS): touch gestures or a touchpad mode, portrait too.
  • Own battle by a shareable code, and the «Максимум» battle AI.
  • Automatic updates on PC and Android.

What you bring

  • Your own copy of Discord Times with the Community Update 1.2.
  • Windows 10 or newer, Linux (x86_64), or macOS 11 or newer.
  • A graphics card with OpenGL 2, which almost any computer has.
  • Android 8 or newer, or an iPhone or iPad with iOS 14 or newer (the iOS version is installed with AltStore or Sideloadly).

Installation

×
  1. Install Discord Times and the Community Update 1.2, if you haven't yet.
  2. Download Razdor from the releases page: Razdor.exe for Windows, razdor for Linux or razdor-macos for macOS.
  3. Put it into the game folder, next to DiscordTimes.exe.
  4. Start it. Razdor finds the game in its own folder; it keeps its saves and settings apart and leaves the game untouched.

Step-by-step guide with pictures: how to install Razdor →

If the game is somewhere else, give its folder in a .env file next to the program: RAZDOR_DT_DIR="C:\Games\Discord Times". If something does not start or plays differently from the original, report it on GitHub with the razdor.log file from %APPDATA%\razdor\ (Windows), ~/.local/share/razdor/ (Linux) or ~/Library/Application Support/razdor/ (macOS).

Phone or tablet (trial versions). Android: download razdor.apk from the releases page, put the game folder into DiscordTimes in internal storage, and allow «All files access». iOS: install razdor.ipa with AltStore or Sideloadly, then copy the game folder to Files → On My iPhone → Razdor → DiscordTimes. Details are in the README.
