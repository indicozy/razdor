# Galaxy A04 (Samsung Remote Test Lab), 2026-11-12

The budget-phone run of the lab plan: Samsung Galaxy A04, 3 GB, MediaTek Helio P35, PowerVR Rogue GE8320,
720×1510, Android, Razdor 1.4.1 (main at ecabad0e, release-signed lab APK), «Тест производительности» →
«Все пресеты» on «Другой берег». Raw lines below (from the app's saved result).

## Reading

- **Whole map is CPU-bound:** 7–8 FPS in 2.5D with a median CPU time of 102–122 ms a frame (frame
  119–141 ms); flat whole map 11 FPS at 51 ms CPU. Zoomed out, the per-frame CPU work is the limit.
- **Near view:** 24.5 FPS (Original 2.5D), 27.2 FPS (flat); CPU 25 ms (2.5D) / 15 ms (flat) of a
  37–40 ms frame, so the rest is the GPU or the driver.
- **«Низкое» gives nothing over «Оригинал»** (24.8 vs 24.5 near, 8.1 vs 8.3 whole map): the 75% render
  scale does not help this GPU, so the near view is not fill-bound.
- **«Среднее»/«Высокое» halve the near view** (12.7 / 10.1 FPS) with CPU only 35–39 ms: the lighting,
  shadows and water cost the GE8320 40–60 ms of GPU a frame.
- **Memory is not a problem:** RSS 182–202 MB on a 3 GB phone. The first map load took 4.2 s.
- Not measured here: the RAM drop with and without (needs an Android-reachable switch).
